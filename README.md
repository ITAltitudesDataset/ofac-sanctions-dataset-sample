## Source & Provenance

The dataset is based on the **U.S. Department of the Treasury, Office of
Foreign Assets Control (OFAC) Specially Designated Nationals and Blocked
Persons (SDN) source data**.

The underlying source snapshot used for the buyer-facing release was
downloaded on **September 28, 2026**.

The commercial dataset adds structured processing, normalization, linked
address and alias organization, documentation, provenance information,
and quality documentation around the source data.
